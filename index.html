Connect your private repo (one time, ~2 min)

  1. 1 · Create a GitHub key ↗
    Sign in if asked. Name, expiry and permissions are filled in for you.
  2. Under Repository access pick Only select repositories → phish-finder.
  3. Check Permissions: Actions, Contents, Workflows = Read and write.
  4. Tap Generate token and copy it (starts with github_pat_).
  5. Paste it below and tap Connect.
