Connect your private repo

This page only holds code. Your brands and results are read live from your private GitHub repo with a key that stays on this phone.

  1. Open Create a GitHub key ↗ (sign in to GitHub if asked). Name, expiry and permissions are filled in for you.
  2. Under Repository access choose Only select repositories and pick phish-finder.
  3. Check Permissions shows: Actions, Contents and Workflows = Read and write (Metadata = Read is automatic). Add any that are missing.
  4. Tap Generate token, then copy the key (starts with github_pat_).
  5. Paste it below and tap Connect.

The key is saved only in this browser (you can remove it any time with “Disconnect”). Nothing is sent anywhere except api.github.com.
